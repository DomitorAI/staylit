# Security policy

## Reporting a vulnerability

Please **do not open a public issue** for a security problem. Report it privately:
[Security → Report a vulnerability](https://github.com/DomitorAI/staylit/security/advisories/new) —
only the maintainers can see the report.

Include what you can: the version (shown in **About StayLit**), the steps to reproduce and what an attacker
could do. Never include personal data. The StayLit log contains no user or computer name and can be attached.

You will get an answer in the report; once a fix is released, the advisory is published with credit to you (if you wish).

## Supported versions

Only the latest release is supported: fixes come as a new version.
