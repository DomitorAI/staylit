# StayLit privacy policy

StayLit is made by DomitorAI. This policy covers every version of StayLit: the one from the GitHub releases
and the one from the Microsoft Store.

## What StayLit collects

**Nothing.** StayLit has no account, no telemetry, no analytics and no advertising. It does not send any
information about you, your computer or how you use it to anyone.

## What stays on your computer

- **Settings** (when StayLit acts, the method, pause on battery, start with Windows) — in your Windows user profile.
- **A log** of what StayLit did (for example when it kept the screen on, or when the screen locked), so you can
  check it or share it when asking for help. The log never contains your user name or computer name.

Both are removed when you uninstall StayLit.

## Connections

- **Microsoft Store version:** none. Updates come from the Microsoft Store.
- **GitHub version:** once a day StayLit asks GitHub (`api.github.com`) for the number of the latest version. The
  request contains no information about you; like any web request, GitHub sees your IP address (see the
  [GitHub privacy statement](https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement)).
  A new version is downloaded only when you click the update notification. You can turn the check off in **Settings**.

## Contact

Questions about privacy: [open an issue](https://github.com/DomitorAI/staylit/issues/new/choose) (issues are public:
do not write personal details there).
